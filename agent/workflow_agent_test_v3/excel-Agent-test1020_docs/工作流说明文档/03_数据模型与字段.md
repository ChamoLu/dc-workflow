# 03 · 数据模型与字段

工作流在「模板配置（template_config）」上维护一组**全局字段**，各节点通过 `#template_config__0__<字段>` 引用上游产出，读写同一个上下文字典。本文档梳理字段清单、各节点输入输出，以及关键数据结构。

## 1. 模板配置全局字段（22 个）

来源：`canvasInfo.templateConfig.data.templateConfig`。

| 字段 | 数据类型 | 含义 | 来源（selectedType） |
|---|---|---|---|
| `fileMd5` | String | 文件 MD5 校验码（下载原始文件用） | source_field |
| `columnName` | String | 栏目名称 | source_field |
| `title` | String | 文章标题（用于解析统计期） | source_field |
| `pushtime` | Time | 发布时间 | source_field |
| `parseFileMd5` | String | 解析文件 MD5 | source_field |
| `pageTitle` | String | 路径（栏目全路径） | source_field |
| `rid` | String | 资源标识（类型_数据id_分表位_数据版本） | source_field |
| `end_date` | String | 截止日期 | source_field |
| `indicator_data` | String | 指标数据 | source_field |

本工作流 `advancedConfigEnabled=false`、无外部工作流依赖（`appDependency.workflowId=""`）、无清理字段。

## 2. 各节点输入 / 输出映射

| 节点 | 输入参数（来源全局字段） | 输出（写回全局字段） |
|---|---|---|
| 2229 造路径 | 无 | `pageTitle`、`title`（硬编码） |
| 2442 指标代码单位 | `pageTitle` | `GZK.ZBDM`→indicator_code、`GZK.ZBMC`→indicator_name、`GZK.ZBDW`→constant_name、`GZK.indicator_release_frequency` |
| 8448 规则库查询转 | `GZK`（Array<Object>） | `GZK.GZKJG`（String/对象数组） |
| 4912 表格解析 | `fileMd5`、`title` | `excel_data`（输出声明名 ExcelData） |
| 8300 表格数据匹配 | `excel_data`(ExcelData)、`GZK.GZKJG`、`GZK.indicator_release_frequency`(PLPL)、`publictime` | `out_data`(OUTDATA)、`unitArray` |
| 4551 转换率查询 | `unitArray.indicator_unit`(raw_unit)、`unitArray.KB_unit`(target_code) | `unitArray.raw_unit / target_code / convert_ratio` |
| 7882 单位清洗 | `out_data`(OUTDATA)、`unitArray`(unitarray) | `out_data`（就地换算） |
| 5230 空值清洗 | `out_data`(OUTDATA) | `out_data`（过滤后） |
| 4589 条件 | 读 `out_data` | — |
| end | 全部模板字段 | 输出 |

> 字段名存在大小写/别名差异：节点 4912 的脚本内部返回 `ExcelData`，其输出声明映射到全局 `excel_data`；节点 8300/7882/5230 脚本内部使用 `OUTDATA`（7882 的输入还写作 `unitarray`），统一映射到全局 `out_data` / `unitArray`。平台在调用脚本时按节点输入参数名组装 `params`，因此脚本内 `params.get("ExcelData")`、`params.get("OUTDATA")` 等是与**节点输入参数名**对应的，而非全局字段名。

## 3. 关键数据结构

### 3.1 `GZK`：规则库列式返回（规则 2442 → 地方经济组）

规则返回的是**按列平行的数组**（列名与字段对应）：

| 列 | 含义 | 调试样例 |
|---|---|---|
| `ZBDM` | 指标代码 | `[1010103100, 1010103242, 1010103174, ...]` |
| `ZBMC` | 指标名称 | `["地区生产总值累计","第一产业累计",...]` |
| `ZBDW` | 指标单位（常量名） | `["万元","万元",...]` |
| `indicator_release_frequency` | 披露频率（常量名） | `["季","季",...]` |
| `unit_ratio` | 单位比例（部分组有） | 本工作流未使用 |

### 3.2 `GZKJG`：列式转对象数组（节点 8448 产出）

按最长数组对齐，逐行组合成对象：

```json
{
  "rule_indicator_code": 1010103100,
  "rule_indicator_name": "地区生产总值累计",
  "rule_constant_name": "万元",
  "rule_unit_ratio": "",
  "indicator_release_frequency": "季"
}
```

### 3.3 `excel_data`（ExcelData）：Excel 解析结果（节点 4912 产出）

每条记录四字段：

```json
{
  "indicator_name": "地区生产总值累计",
  "indicator_data": "441442",
  "indicator_unit": "万元",
  "end_date": "2026-02-28"
}
```

> 节点 4912 的原始返回结构为 `{"code":0,"msg":"success","ExcelData":[...]}`；在“校验模式”（`_dc_validate`）下额外带 `_dc_evidence`（每条记录到单元格的溯源，见 04）。

### 3.4 `out_data`（OUTDATA）：最终记录（节点 8300 建立，7882/5230 续处理）

匹配成功后挂上代码与库表单位：

```json
{
  "indicator_code": "1010103100",
  "indicator_name": "地区生产总值累计",
  "indicator_data": "441442",
  "indicator_unit": "万元",
  "KB_unit": "万元",
  "convert_ratio": "1",
  "unit_ratio": "",
  "publictime": "",
  "end_date": "2026-02-28",
  "remark": "",
  "PLPL": "",
  "SJPLLB": ""
}
```

### 3.5 `unitArray`：单位换算批量入参（8300 收集，4551 回填，7882 消费）

- 8300 输出去重后的列：`{"indicator_unit":[...采集单位], "KB_unit":[...库表单位]}`；为空时兜底为 `["-"]`。
- 4551（rule206 换算率组）按笛卡尔/组合查询，回填 `convert_ratio`：`{"indicator_unit":[...],"KB_unit":[...],"convert_ratio":[1.0,1.0,...]}`。

### 3.6 空占位（empty）

- 8300：一条都没匹配上时，输出单条 `indicator_code="empty"` 的记录。
- 5230：全部被过滤后，输出 `{"indicator_code":"empty","indicator_data":"empty","end_date":"","remark":"empty"}`。
- 条件 4589 依据 `empty` / 空数组判断是否拦截。

## 4. 字段在链路上的生命周期（顺序视角）

```
2229 产出 pageTitle/title
  → 2442 用 pageTitle 查得 GZK（列式）
  → 8448 生成 GZK.GZKJG（对象数组）
  → 4912 用 fileMd5/title 生成 excel_data（四字段行）
  → 8300 名称匹配：excel_data + GZKJG ⇒ out_data（含 code/KB_unit）+ unitArray（去重单位）
  → 4551 用 unitArray 查换算率 ⇒ unitArray.convert_ratio
  → 7882 用 convert_ratio 换算 out_data.indicator_data
  → 5230 剔除空值（可能保留 empty 占位）
  → 4589 判定：含 empty/为空 ⇒ 终止；否则 ⇒ end 输出 out_data
```
