# 05 · 节点详解 · 条件节点与规则节点

## 一、条件节点 4589 · 发放_数据拦截

`condition_1785918771965_4589`，对最终数据做“是否可发放”的最后拦截。两个分支端口：

| 分支 | 端口 ID | 连接 |
|---|---|---|
| **IF** | `out_d32eda70-4195-47c1-9bf9-e06c4f96a97b` | **悬空（无连线）→ 命中即终止、不产出** |
| **ELSE** | `out_8560eca8-0aa8-491c-ad77-018514f27256` | → end（数据有效才输出） |

### IF 分支（logic = `and`，三个条件同时成立）

| 左值 | 数据类型 | 操作符 | 右值 |
|---|---|---|---|
| `#template_config__0__out_data.indicator_code` | String | `contains` | `'empty'` |
| `#template_config__0__out_data` | Array&lt;Object&gt; | `isEmpty` | `''`（空） |
| `#template_config__0__out_data.remark` | String | `contains` | `'empty'` |

> 平台对数组字段的条件是按**元素存在性**判断：`out_data` 中“存在某条记录的 `indicator_code` 含 empty”、“存在某条记录的 `remark` 含 empty”，并结合 `out_data` 为空数组，综合判定是否为空数据。ELSE 为兜底分支（无条件）。

### 语义

- 经 5230 清洗后，若没有任何有效指标（`out_data` 为空或只含 `empty` 占位），命中 IF → 流程在画布上终止，**不到结束节点、不发送**。
- 若存在有效记录，则走 ELSE → 结束节点，输出最终 `out_data`。

> 与生产工作流相比，本工作流只有这一个拦截条件，没有月末/季末/年末、代码长度、发布日期等更多内审节点。

## 二、规则节点（2 个，均为动态查询规则 rule206）

两个自定义规则节点都引用同一条**动态查询规则** `ruleId = 206`「EDB指标代码查询」（版本 V22，共 5 个规则组）。节点上记录的是平台旧整数 `ruleIndexId`，与规则中心雪花 ID 的对应关系如下（已用 SQL 语义核实）：

### 规则节点 2442 · 预标注-指标代码单位

| 项 | 值 |
|---|---|
| 类型 | `custom_rule` / `ruleType=dynamic_query` |
| ruleId / ruleIndexId | `206` / `7167`（旧整数 ID） |
| 实际规则组（按 SQL 语义） | **「地方经济运行代码\比例\单位\名称查询」**（雪花组 ID `2082796849787101185`） |
| 输入 | `pageTitle`（String，精确匹配） |
| 输出（列式） | `indicator_code`(→GZK.ZBDM)、`indicator_name`(→GZK.ZBMC)、`constant_name`(→GZK.ZBDW)、`indicator_release_frequency` |

执行的 SQL（`dim_4` 库）：

```sql
select distinct a.indicator_code,a.indicator_name,c.constant_name,d.constant_name indicator_release_frequency
from dim_EDB_source_collection_indicator_table a
inner join dim_EDB_localecon_indicator b on b.indicator_code=a.indicator_code
inner join dim_EDB_localecon_constant c on c.type_code=2000 and c.constant_code=b.indicator_unit
inner join dim_EDB_localecon_constant d on d.type_code=1000 and d.constant_code=b.indicator_release_frequency
where a.pageTitle=${pageTitle}
limit 5000
```

即：**按栏目路径 `pageTitle` 查出该页面应当包含的全部指标（代码/名称/单位/频率）**。本测试 `pageTitle` 为上街区统计月报路径，返回 21 个指标。

### 规则节点 4551 · 预标注-转换率查询

| 项 | 值 |
|---|---|
| 类型 | `custom_rule` / `ruleType=dynamic_query` |
| ruleId / ruleIndexId | `206` / `3549`（旧整数 ID） |
| 实际规则组（按 SQL 语义） | **「查询单位换算率」**（雪花组 ID `2074016997430190081`） |
| 输入（AND，精确） | `raw_unit`（采集单位，取 `unitArray.indicator_unit`）、`target_code`（库表单位，取 `unitArray.KB_unit`） |
| 输出 | `raw_unit`、`target_code`、`convert_ratio`（回填 `unitArray`） |

执行的 SQL：

```sql
select a.raw_unit,a.target_code,a.convert_ratio
from dim_EDB_unit_convert_table a
where raw_unit IN(${raw_unit}) and target_code IN(${target_code})
```

即：按“采集单位 × 库表单位”组合批量查询换算率（例如 亿元→万元、万吨→吨）。本测试采集单位与库表单位一致（万元、%），换算率均为 1。
