# 06 · 外部依赖与运行环境

本工作流的外部依赖很少：**一条动态查询规则（rule206）**、**一个内网文件下载接口**、**两个 Python 第三方库**。没有 Agent、大模型、Skill、标注模板、feel_table 决策表等依赖。

## 1. 外部依赖清单

| 依赖 | 类型 | 被谁使用 | 说明 |

| 动态查询规则 **rule206**「EDB指标代码查询」（V22，5 组） | 规则中心 | 规则节点 2442、4551 | 查指标库与单位换算率；详见 [../外部规则与资产/rule_206_SQL模板.md](../外部规则与资产/rule_206_SQL模板.md) |

## 3. 运行环境特征

- 脚本节点运行在平台的 Python3 执行环境中，入口固定 `main(params)`。
- 脚本 4912 直接访问**内网地址** `service-1.example.invalid`，因此该工作流只能在能访问该内网的执行环境中运行。
- 脚本超时：6 个脚本节点均配置 `timeout=120` 秒；其中 8448 重试 1 次，其余重试 0 次（2229 重试 0）。
- 运行方式：手动触发（`runType=manual`），不写结果表（`tableName=null`）。
