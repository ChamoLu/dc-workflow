## 四、重要约定（阅读前须知）

1. **节点 ID 尾号**：平台节点 ID 形如 `<类型>_<时间戳>_<4位尾号>`，文档中一律用**尾号**指代节点（如“脚本 8300”“条件 3451”）。完整 ID 见各节点详解与 `02_流程编排与节点清单.md`。
2. **字段引用语法**：节点间引用全局变量使用 `#template_config__0__<字段>`，嵌套对象写作 `#template_config__0__GZK.ZBDM`；参数值数组首元素固定为 `#template_config__0__templateConfigId`。详见 `03_数据模型与全局字段.md`。
3. **悬空分支 = 流程终止**：部分条件节点的 IF 分支（命中“空/empty”）在画布上**没有连出任何连线**，命中即终止该条流程（不进入后续、不发送）。完整清单见 `05_节点详解_条件节点.md`。
4. **`empty` 占位约定**：匹配不到、解析为空或无异常时，各脚本会输出含 `indicator_code/indicator_name/indicator_data = "empty"` 的占位记录，由后续条件节点识别并拦截。
5. **外部文件下载基址**：脚本/解析器统一通过内网地址 `http://service-1.example.invalid/api/file/download/{fileMd5}`（或 `{markdownMD5}`）下载原始文件。
6. **只读声明**：整理过程中仅对平台执行了 GET/POST 查询类接口（`detail`、`configDetail`、`tableValue`、`lastVersionDetail` 等），未点击任何保存 / 发布 / 调试 / 删除按钮。
