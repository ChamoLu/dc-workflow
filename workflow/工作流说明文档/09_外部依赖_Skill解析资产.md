## 5. 如何新增一个站点的解析（扩展方式，仅说明，未改动）

SKILL.md 给出了明确的扩展约定：

- **Excel/HTML（Python 解析器）**：在对应 Skill 目录放一个审核过的 `.py`（实现 `main(params)`，用文件服务下载，返回 `{code,msg,ExcelData 或 OUTDATA}`），再在 `python-page-title-config.json` 的 `mappings` 里**新增且仅新增一条**：
  ```json
  { "pageTitle": "工作流实际传入的完整路径", "PythonFile": "后台 Python 文件的完整文件名.py" }
  ```
  不需要为每个解析器在画布上新建节点（一个共享执行节点即可）。
- **Markdown（提示词）**：新增一份站点 `.md`，在 `prompt-pageTitle-config.json` 的 `mappings` 里加一条 `{ "pageTitle": ..., "PromptFileName": "xxx.md" }`。
- 配置里的 `pageTitle` 必须与工作流实际传入的采集路径**完全相等**（含层级与全角字符），文件名必须与 Skill 文件**完全一致**，否则 Agent 会按未匹配处理并返回 `empty`，对应条件节点即终止该流程。
