# 08 · 节点详解 · 人工标注节点（mark_task）

共 **3 个标注任务节点**，用于内审确认存在问题数据后，按文件类型把数据派发给 **EDB 标注团队** 人工修订。三个节点配置基本相同，仅绑定的**表单模板**与入参字段不同。

## 1. 三个标注任务的共同配置

| 配置项 | 值 |
|---|---|
| 任务类型 markTaskTypeCode | `MARK0018`（typeName = **EDB标注（团队）**） |
| 字段来源 fieldSource | `taskTemplate`（使用任务模板表单） |
| 领取/分配策略 filterTaskPolicy | `["activeAccept", "autoAssign"]`（主动领取 + 自动分配） |
| 标注策略 markTaskPolicyCode | `activeAccept`（主动领取） |
| 难度 difficulty | 3 |
| 时限 timeLimit | **1440 分钟（24 小时）** |
| 输出 outputConfig | `markTaskId` |
| 优先级 priorityParams | 无 |
| 完成后流向 | 统一进入脚本 4185（合并问题数据） |

## 2. 三个节点对比

| 节点 | 名称 | 任务模板 ID | 模板名称 | 节点入参 markFields |
|---|---|---|---|---|
| 3209 | 内审_excel标注 | `2103026958354526211`（211） | Excel标注第一版 | `fileMd5`（表格文件）、`warning_data`（问题数据） |
| 3138 | 内审_json标注 | `2103026958354526212`（212） | json标注配置第一版 | `indicator_data`、`indicator_name`、`end_date`、`publictime`、`indicator_unit`、`warning_data` |
| 6472 | 内审_MD标注 | `2103026958354526213`（213） | MD标注第一版 | `markdownMD5`（Markdown 文件）、`warning_data` |

触发条件（由条件 1127 决定）：

- 文件类型命中 xls/xlsx/csv → **3209 excel 标注**；
- 命中 json → **3138 json 标注**；
- txt / html / htm / shtml / 其它（含 md）→ **6472 MD 标注**（三种共用一个模板）。

## 3. 各模板表单字段（标注人员看到的内容）

### 模板 211「Excel标注第一版」

- **文件区（file-reader）**：`fileMd5` 表格文件（类型 xls，只读展示原始 Excel）。
- **问题数据表单（general-form，字段前缀 `warning_data.`）**：

| 字段 | 表单标签 | 控件 | 状态 | 是否必填 |
|---|---|---|---|---|
| warning_data.indicator_name | 指标名称 | 文本 | editable | 否 |
| warning_data.indicator_data | 指标数据 | 文本 | editable | **是** |
| warning_data.indicator_code | 指标代码 | 文本 | editable | **是** |
| warning_data.end_date | 截止日期 | 日期 | editable | **是** |
| warning_data.publictime | 发布时间 | 日期 | editable | 否 |
| warning_data.unit_ratio | 单位比例 | 文本 | readonly | 否 |
| warning_data.indicator_release_frequency | 披露频率 | 文本 | readonly | 否 |

### 模板 212「json标注配置第一版」

- **采集原始值（全部 readonly，供对照）**：

| 字段 | 标签 | 状态 |
|---|---|---|
| indicator_data | 采集指标数据 | readonly |
| indicator_name | 采集指标名称 | readonly |
| end_date | 采集截止日期 | readonly |
| publictime | 采集发布时间 | readonly |
| indicator_unit | 采集指标单位 | readonly |

- **问题数据表单（`warning_data.`）**：

| 字段 | 表单标签 | 控件 | 状态 | 是否必填 |
|---|---|---|---|---|
| warning_data.indicator_name | 指标名称 | 文本 | editable | 否 |
| warning_data.indicator_data | 指标数据 | 文本 | editable | **是** |
| warning_data.indicator_code | 指标代码 | 文本 | editable | **是** |
| warning_data.end_date | 截止日期 | 日期 | editable | **是** |
| warning_data.publictime | 发布时间 | 日期 | editable | 否 |
| warning_data.remark | 备注 | 文本 | editable | 否 |
| warning_data.unit_ratio | 单位比例 | 文本 | readonly | 否 |
| warning_data.indicator_release_frequency | 披露频率 | 文本 | readonly | 否 |

> JSON 模板没有文件预览区，改为顶部展示 5 个采集原始字段（只读），并多了一个可编辑的「备注」字段。

### 模板 213「MD标注第一版」

- **文件区（file-reader）**：`markdownMD5` Markdown 文件（展示网页转换后的 Markdown）。
- **问题数据表单（`warning_data.`）**：

| 字段 | 表单标签 | 控件 | 状态 | 是否必填 |
|---|---|---|---|---|
| warning_data.indicator_name | 指标名称 | 文本 | editable | 否 |
| warning_data.indicator_data | 指标数据 | 文本 | editable | **是** |
| warning_data.indicator_code | 指标代码 | 文本 | editable | **是** |
| warning_data.end_date | 截止日期 | 日期 | editable | **是** |
| warning_data.publictime | 发布时间 | 日期 | editable | 否 |
| warning_data.remark | 备注 | 文本 | editable | 否 |
| warning_data.unit_ratio | 单位比例 | 文本 | readonly | 否 |
| warning_data.indicator_release_frequency | 披露频率 | 文本 | readonly | 否 |

## 4. 标注结果如何回写

1. 标注人员在表单里修订的是 `warning_data`（问题数据）里的**指标数据、指标代码、截止日期、发布时间、备注**等字段；`单位比例`、`披露频率` 为只读，供参考。
2. 三个标注任务完成后都流入脚本 **4185**，执行 `OUTDATA.extend(warningdata)`，把（修订后的）问题数据追加合并进正常数据 `OUTDATA`。
3. 合并后的 `out_data` 进入结束节点“发送”。
