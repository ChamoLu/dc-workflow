# 03 · 数据模型与全局字段

DC 工作流中，所有节点通过**模板配置（templateConfig）里的全局变量**传递数据。本工作流的全局变量在画布的“模板配置”节点中声明，共 **27 个顶层字段**，分为：

- **来源字段（source_field）**：由采集任务在触发工作流时传入（只读输入）；
- **手工字段（manual）**：工作流运行过程中各节点写入的中间/结果变量。

字段引用统一写成 `#template_config__0__<字段>`，嵌套对象用点号，如 `#template_config__0__GZK.ZBDM`。节点参数 `value` 数组的首元素固定为 `#template_config__0__templateConfigId`（模板实例标识）。

---

## 1. 起点节点（start）声明的 18 个采集入参

开始节点 `crawlList` 声明从采集侧接收的字段（运行时实际可用的来源字段，比模板里 source_field 多 `columnLink`、`data_target_table`、`label` 等）：

```
label, pushtime, end_date, parseFileMd5, columnLink, columnName, pageTitle,
release_frequency, data_target_table, fileType, fileMd5, title, publictime,
indicator_unit, indicator_name, indicator_data, rid, markdownMD5
```

| 字段 | 含义 |
|---|---|
| `label` | 标签 |
| `pushtime` | 采集推送时间 |
| `end_date` | 截止日期（数据所属期） |
| `parseFileMd5` | 解析文件 MD5 |
| `columnLink` | 栏目链接 |
| `columnName` | 栏目名称 |
| `pageTitle` | 采集页面路径（**路由 Agent 与规则库查询的核心入参**） |
| `release_frequency` | 披露频率 |
| `data_target_table` | 数据目标表 |
| `fileType` | 文件类型（**文件类型路由依据**，如 xls/xlsx/csv/json/txt/html/htm/shtml/md） |
| `fileMd5` | 原始文件 MD5（Excel/JSON/TXT 解析器据此下载） |
| `title` | 文章标题 |
| `publictime` | 信息发布日期 |
| `indicator_unit` | 指标单位 |
| `indicator_name` | 指标名称 |
| `indicator_data` | 指标数据 |
| `rid` | 资源标识（类型_数据id_分表位_数据版本） |
| `markdownMD5` | 转换后 Markdown 文件 MD5（HTML/Markdown 解析据此下载） |

## 3. 嵌套对象结构

### 3.1 `out_data`（最终输出，Array&lt;Object&gt;，12 个子字段）

| 子字段 | 类型 | 说明 |
|---|---|---|
| `end_date` | String | 截止日期 |
| `indicator_data` | String | 指标数据（单位换算后） |
| `indicator_name` | String | 指标名称 |
| `indicator_code` | String | 指标代码（标准库代码） |
| `unit_ratio` | String | 单位比例（规则库给出的比例） |
| `pushtime` | String | 发布时间 |
| `remark` | String | 备注（内审异常原因，多个问题用中文分号「；」拼接） |
| `indicator_release_frequency` | String | 披露频率（月/季/半年/年） |
| `indicator_unit` | String | 采集到的单位（原始单位） |
| `KB_unit` | String | 库表单位（规则库标准单位） |
| `convert_ratio` | String | 转换率（实际换算用） |
| `publictime` | String | 信息发布日期 |

### 3.2 `GZK`（规则库原始，Array&lt;Object&gt;，6 个子字段）

| 子字段 | 类型 | 说明 |
|---|---|---|
| `ZBDM` | String | 规则库指标代码（指标代码列） |
| `ZBMC` | String | 规则库指标名称 |
| `ZBDW` | String | 规则库指标单位 |
| `unit_ratio` | String | 单位比例 |
| `GZKJG` | String | 规则库结果（由脚本 8448 把列式字段重组为**对象数组**，见下） |
| `indicator_release_frequency` | String | 披露频率 |

脚本 8448 生成的 `GZK.GZKJG` 是一个对象数组，每个元素：

```json
{
  "rule_indicator_code": "规则库指标代码",
  "rule_indicator_name": "规则库指标名称",
  "rule_constant_name": "规则库标准单位",
  "rule_unit_ratio": "单位比例",
  "indicator_release_frequency": "披露频率"
}
```

### 3.3 `excel_data`（Excel/HTML 解析结果，Array&lt;Object&gt;，4 个子字段）

| 子字段 | 类型 | 说明 |
|---|---|---|
| `end_date` | String | 截止日期 |
| `indicator_data` | String | 指标数据 |
| `indicator_name` | String | 指标名称 |
| `indicator_unit` | String | 指标单位 |

> 解析器返回的字段名为 `ExcelData`（excel skill 解析器）或 `OUTDATA`（html skill 解析器），代码执行节点把结果映射到全局 `excel_data`，下游匹配脚本 8300 以入参名 `ExcelData` 读取。

### 3.4 `unitArray`（单位匹配使用，Array&lt;Object&gt;，3 个子字段）

| 子字段 | 类型 | 说明 |
|---|---|---|
| `indicator_unit` | String | 采集单位（去重后的数组） |
| `KB_unit` | String | 库表单位（去重后的数组） |
| `convert_ratio` | String | 转换率（由 rule206 换算率查询回填） |

`unitArray` 是**列式结构**（每个字段是一个数组，按下标对齐），由匹配脚本 8300 / 2938 收集去重单位，交给规则 4551 / 2817 批量查换算率，再由清洗脚本 7882 / 1414 按下标重组为 `(采集单位, 库表单位) → 换算率` 映射。

### 3.5 `warning_data`（问题数据，Array&lt;Object&gt;，13 个子字段）

| 子字段 | 类型 | 说明 |
|---|---|---|
| `end_date` | String | 截止日期 |
| `indicator_data` | String | 指标数据 |
| `indicator_name` | String | 指标名称 |
| `indicator_code` | String | 指标代码 |
| `unit_ratio` | String | 单位比例 |
| `remark` | String | 备注（异常原因汇总） |
| `indicator_release_frequency` | String | 披露频率 |
| `indicator_unit` | String | 采集到的单位 |
| `KB_unit` | String | 库表单位 |
| `convert_ratio` | String | 转换率 |
| `publictime` | String | 信息发布日期 |
| `is_zero` | String | 为零数据（规则 682 价格不可为零，码值 1005） |
| `problem_fin_time` | String | 非末数据（1002 非月末 / 1003 非季末 / 1004 非年末 / 1005 非半年末） |

## 4. 数据在节点间的典型形态（以一条指标为例）

以 Excel 分支为例，一条指标数据在各节点的演变：

1. **采集传入**：`fileMd5`、`pageTitle`、`fileType`、`publictime`、`title` 等。
2. **规则 2442（rule206）**：按 `pageTitle` 查出 GZK 列式数组 `ZBDM / ZBMC / ZBDW / unit_ratio / indicator_release_frequency`。
3. **脚本 8448**：重组为 `GZK.GZKJG` 对象数组。
4. **Agent 3708 + 脚本 4912**：按 `pageTitle` 选解析器并运行，输出 `excel_data`（含 `indicator_name/indicator_data/indicator_unit/end_date`）。
5. **脚本 8300**：按名称匹配 GZKJG，得到 `indicator_code`、`KB_unit`、`unit_ratio`，输出 `out_data` 与 `unitArray`。
6. **规则 4551（rule206）**：用 `unitArray` 批量查 `convert_ratio`。
7. **脚本 7882**：按换算率对 `indicator_data` 做乘法，写回 `out_data`。
8. **脚本 5230 + 条件 3451**：剔除空/未匹配数据。
9. **脚本 2034 / 6387**：校验截止日期等，异常记录进 `warning_data.remark`。
10. **标注任务**：问题数据以表单呈现给标注人员修订。
11. **脚本 4185**：`OUTDATA.extend(warningdata)` 合并，得到最终 `out_data` 发送。
