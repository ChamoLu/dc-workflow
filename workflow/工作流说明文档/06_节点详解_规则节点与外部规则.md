# 06 · 节点详解 · 规则节点（custom_rule）与外部规则

共 **9 个自定义规则节点**，全部调用平台规则引擎（serviceApiId=25），分两类：

- **dynamic_query（动态查询）**：按输入参数执行一段 SQL，返回一行或多行结果，共 8 个节点（rule206 × 6、rule682 × 3，实际节点数 9 个中 2442 + 4 个转换率查询 = 5 个 rule206，3 个 rule682，1 个 rule404 决策表）；
- **feel_table（决策表）**：按输入命中 DMN 决策表，输出映射值，共 1 个节点（rule404）。

> 节点配置里有两个 ID：`ruleId`（规则编号，如 206/404/682）与 `ruleIndexId`（具体规则组/版本的索引，画布上用的是**旧整数 ID**，如 7167/3549/14878…；规则当前版本在规则中心里以雪花 ID 分组）。两者在接口层未做逐字 ID 映射，本文按“规则名 + 输入输出 + SQL 语义”对应。

## 2. 规则 206「EDB指标代码查询」

动态查询规则，V22，共 **5 个规则组**，全部走数据源 `dim_4`（dataSourceId=2068983833818808322），返回策略 ALL，仅可用于画布配置。完整 SQL 见 [外部规则与资产/rule_206_EDB指标代码查询_SQL模板.md](../外部规则与资产/rule_206_EDB指标代码查询_SQL模板.md)。

| 规则组 | 雪花 ruleIndexId | 用途 | 动态输入 | 输出 |
|---|---|---|---|---|
| 0 新宏观 | 2071900657280163842 | 新宏观代码/比例/单位/名称 | pageTitle | indicator_code, indicator_name, constant_name, **unit_ratio**, frequency |
| 1 查询单位换算率 | 2074016997430190081 | 查 raw_unit→target 的换算率 | raw_unit, target_code（AND） | raw_unit, target_code, **convert_ratio** |
| 2 国际宏观 | 2082796849719992322 | 国际宏观代码/比例/单位/名称 | pageTitle | 同组 0 |
| 3 **地方经济运行** | 2082796849787101185 | 本工作流实际对应的地方经济指标查询 | pageTitle | indicator_code, indicator_name, constant_name, frequency（**不含 unit_ratio**） |
| 4 行业 | 2082796849833238529 | 行业代码/比例/单位/名称 | pageTitle | 同组 0 |

### 节点 2442（ruleIndexId 7167，预标注-指标代码单位）

- 按采集传入的 `pageTitle` 精确匹配 `dim_EDB_source_collection_indicator_table.pageTitle`，关联地方经济指标表、单位常量表、频率常量表，取回该页面下的**全部指标代码、名称、单位、披露频率**（`limit 5000`，返回 ALL）。
- 结果是**列式**的（每个输出字段一个数组），写入 `GZK` 的 ZBDM/ZBMC/ZBDW/indicator_release_frequency 四列，再由脚本 8448 转成 `GZK.GZKJG` 对象数组。
- 地方经济组（组 3）的 SQL 输出**没有 unit_ratio**，节点输出也只映射了 4 个字段，因此本工作流里 `GZK.unit_ratio`（以及 GZKJG 里的 `rule_unit_ratio`）实际为空；单位换算是后续用 rule206 **组 1（换算率）** 单独完成的。

### 节点 4551 / 2817 / 9431 / 7304（ruleIndexId 3549，单位换算率）

对应规则组 1，SQL：

```sql
select a.raw_unit, a.target_code, a.convert_ratio
from dim_EDB_unit_convert_table a
where raw_unit IN(${raw_unit}) and target_code IN(${target_code})
```

- 数组型（4551/2817）：`raw_unit`、`target_code` 分别传入 `unitArray.indicator_unit`、`unitArray.KB_unit` 两个去重数组（平台用 `IN(...)` 批量查询），返回的 `convert_ratio` 按行写回 `unitArray.convert_ratio`。
- 标量型（9431/7304）：传入单个 `indicator_unit`、`KB_unit`，输出单个 `convert_ratio`。
- 查不到换算率时，后续清洗脚本默认换算率为 1（即不换算）。

## 3. 规则 404「EDB单位标准化」（feel_table 决策表）

- 类型：DMN 决策表，版本 V5，`hitPolicy = UNIQUE`（唯一命中）。
- 输入：`indicator_unit`；输出：`indicator_unit_out`（在节点 2952 中直接回写到全局 `indicator_unit`）。
- 共 **2279 条**映射规则，真实数据行须从 `ruleEngine/tableValue` 接口拉取（`configDetail` 返回的 infoList 为 null）；完整数据见 [外部规则与资产/rule_404_EDB单位标准化决策表_2279条.csv](../外部规则与资产/rule_404_EDB单位标准化决策表_2279条.csv)。
- 绝大多数规则是“单位自身 → 自身”的归一化（如 `万人→万人`），少数是别名/写法统一。
- **仅 JSON 分支（链 D）使用**：脚本 9513 匹配后，单位先经 2952 标准化，再进 7304 查换算率。其他链路直接用规则库返回的标准单位，不经此决策表。

## 4. 规则 682「EDB数据特殊性查询」

动态查询规则，V4，共 **5 个规则组**，数据源同为 `dim_4`。完整 SQL 见 [外部规则与资产/rule_682_EDB数据特殊性查询_SQL模板.md](../外部规则与资产/rule_682_EDB数据特殊性查询_SQL模板.md)。

| 规则组 | 雪花 ruleIndexId | 输出字段/码值 | 含义 |
|---|---|---|---|
| 0 价格不可为零入库 | 2100863914902134785 | is_zero = **1005** | 特定价格类指标（维度码 10101/10102/10112/…）必须有数据/不可为零 |
| 1 截止日期不为月末必错 | 2100866155633549314 | problem_fin_time = **1002** | 该指标**必须**为月末，且无例外记录 |
| 2 截止日期不为季末必错 | 2100893349355159554 | problem_fin_time = **1003** | 该指标**必须**为季末，且无例外记录 |
| 3 截止日期不为年末必错 | 2100893349430657025 | problem_fin_time = **1004** | 该指标**必须**为年末，且无例外记录 |
| 4 截止日期不为半年末必错 | 2101956092384337922 | problem_fin_time = **1005** | 该指标**必须**为半年末，且无例外记录 |

**关键实现机制（容易看反）**：这些 SQL 都用 `LEFT JOIN dim_EDB_usrSJTSXB`（数据特殊性/例外表）并以 `b.indicator_code is null` 为条件。即：

- 例外表 `dim_EDB_usrSJTSXB` 里记录的是“**该指标在某特殊规则下可豁免**”的记录；
- 当一个指标**没有**对应特殊码（1002/1003/1004/1005）的豁免记录时，SQL 才返回该指标并带上对应的特殊码；
- 因此**返回 1002/1003/1004 表示“该指标按规则必须是月末/季末/年末”**，而不是“它已经不是月末”。

工作流里画布节点 850/8359/1834（旧 ruleIndexId 14878/14905/14917）分别对应“非月末/非季末/非年末”三组查询：

- 输入 `warning_data.indicator_code`，命中后把特殊码写回 `warning_data.problem_fin_time`；
- 随后脚本 6387 再判断：`problem_fin_time` 含 1002 且实际 `end_date` 不是月末 → 备注「非月末数据」；含 1003/1004 同理。
- 画布上**没有**单独的“非半年末（1005）”节点，半年末由 9075 的 ELSE 分支直接进 6387，在脚本 6387 内部按频率判断；组 0 的“价格不可为零（is_zero=1005）”在本工作流节点中未被引用（脚本 2034/6387 注释均明确“不再校验为零”）。

## 5. 规则数据流转小结

1. **2442（rule206 组3）**：`pageTitle → 该页面全部指标代码/名称/单位/频率`（GZK）；
2. **2952（rule404，仅 JSON）**：`采集单位 → 标准单位写法`；
3. **4551/2817/9431/7304（rule206 组1）**：`(采集单位, 库表单位) → 换算率 convert_ratio`；
4. **850/8359/1834（rule682 组1/2/3）**：`指标代码 → 必须满足的周期末特殊码 problem_fin_time`，供 6387 复核。
